# User experiments

Each guide holds the experiment story (acceptance criteria and hours), the method, the script, the observation sheet and the results table.

| Sprint | Hypothesis | Guide | Experiment stories |
|---|---|---|---|
| 1 | H1 Visibility of ideas | [investor-experiment.md](investor-experiment.md) | US017 Investor experiment |
| 2 | H2 Feedback | [h2-feedback-experiments.md](h2-feedback-experiments.md) | US021 Investor feedback, US022 Student feedback |
| 2 | H3 Student profiles | [h3-profile-experiment.md](h3-profile-experiment.md) | US023 Profile experiment |

Always report which method was used (usability test, interview or questionnaire). Add the full results to the appendix of the final report, and place every improvement that comes out of an experiment in the Product Backlog, under an existing or a new user story.
